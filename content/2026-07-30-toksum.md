Every time you call an LLM API, you pay for tokens, not words. Most people don't know their real token count until they get a big bill or a "context too long" error. I tried **toksum**, a Python library that helps you count tokens and guess the cost before you send anything. This post explains what it does, how to use it, and what could be better.

## What is TOKSUM?

**toksum** — A Python library (`pip install toksum`) that counts tokens and estimates costs for over 300 models from more than 34 companies, like OpenAI, Anthropic, Google, and Meta.

**Why it matters** — Every AI model splits text into tokens differently. So guessing "words × 1.3" doesn't work well when you're comparing something like GPT-4 and Claude.

## Understanding Tokens

* AI models don't read words — they read **tokens**, small pieces of text. The same sentence can turn into a different number of tokens depending on the model.
* Tokens decide both your bill and how much text the model can handle at once. If you don't count them, you might get a surprise bill or a cut-off response.
* toksum's job is simple: tell you the token count *before* you send the request, not after.

> Token count isn't just a small detail — it's what your bill and your text limit are actually based on.

## Multi-Model Support

toksum gives you one simple way to check tokens, instead of learning a different method for each AI company.

This is useful when you want to:

- Compare how many tokens different models use for the same text
- Estimate cost when using more than one model in a project
- Switch models easily without changing your code much

One thing to know — **OpenAI models** get an exact count using their real tokenizer. Other models, including Claude, get an estimated count that's usually close but not 100% exact (within about 10-20%). So if you need an exact number for Claude, treat toksum's answer as a helpful guess, not the final word.

## Token Counting

The library is simple to use. You can count tokens for plain text, or for a full conversation with multiple messages:

```python
from toksum import TokenCounter
counter = TokenCounter("gpt-4")
messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "What is the capital of France?"},
    {"role": "assistant", "content": "The capital of France is Paris."}
]
total_tokens = counter.count_messages(messages)
print(f"Total conversation tokens: {total_tokens}")
```

**`count_tokens(text, model)`** — a simple function that gives you the token count for any text and model.
**`TokenCounter(model)`** — a reusable tool you set up once, then use again and again for the same model.
**`UnsupportedModelError` / `TokenizationError`** — two error types the library gives you, one for models it doesn't know, and one for when counting fails.

## What I Learned

- Tokens, not words, are what really matters when using AI models — cost and limits are both based on tokens.
- Most companies charge different prices for input and output tokens, so check both.
- Counting tokens before you send a request is quick and easy, and it can save you from mistakes.
- One tool covering 30+ providers is handy for comparing, but remember: exact for OpenAI, estimated for everyone else.

## My Ideas to Improve TOKSUM

- **Show where text splits** — a simple view showing exactly where a sentence breaks into tokens would help people understand costs better.
- **Compare costs easily** — one command that shows the cost across many models at once, instead of checking each one by one.
- **Spot repeated text** — a feature that flags repeated or unnecessary text so you can shorten your prompt before sending it.

## Conclusion

toksum won't give you a perfect count for every model, especially outside of OpenAI, but it's a quick and easy way to estimate tokens and cost across many AI providers. Trying it out taught me that a lot of what matters in AI — cost, limits, speed — comes down to one small number most people never check.
